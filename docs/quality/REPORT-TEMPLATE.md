# 独立验收报告模板

复制为 docs/quality/reports/YYYY-MM-DD-阶段-短SHA.md。模板未填写不表示任何通过。

## 身份与范围

- 报告人 / 角色：
- 完整待测代码 SHA、对应文档 / 契约版本：
- 独立 checkout 路径、系统 / Python / 浏览器版本：
- 阶段、案例 ID 范围、测试材料来源：
- 服务 / App / frontend / build 身份：
- Fake / 真实外部服务、用户授权范围：

## 结果

| 案例 | PASS / FAIL / NOT_RUN / BLOCKED | 实际步骤与观察 | 证据 |
|---|---|---|---|

## 命令

实际执行的完整命令、退出码、结果摘要、日志位置。没有执行的命令不填 passed。

## 缺陷

每条列代码 SHA、案例 ID、严重度、最小复现、预期、实际、证据和影响。产品修复交执行者；测试分支的增补测试记录提交。

## 门结论

分别给 DEV 自测复核、独立模拟 QA、真实 provider、真实样板、单机五日、双机结果。说明未测和未关闭问题；不能把某一层通过扩写为完整通过。

## 给执行者的下一步

明确需要修复 / 复验的案例，新的交接 SHA 如何填写。复验另写报告，保留旧证据。
