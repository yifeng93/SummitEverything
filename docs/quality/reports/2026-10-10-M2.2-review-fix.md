# M2.2 独立审查修复：核实依据不能为空

日期：2026-10-10。此为 M2.2 既有开发候选的窄范围 P2 修复记录，不是独立 QA 总报告。

## 缺陷与修复

独立 reviewer 指出，直接调用 outcomes API 的客户端可传仅含空白的 `user_outcome_evidence`，从而把 unknown action 改成 succeeded / failed，却没有可审计依据。

`UserOutcome.evidence` 现在在模型边界去除首尾空白并拒绝空字符串。缺少实质依据返回 422；Action 状态继续为 unknown。有效字符串保存为去除外围空白的形式。
