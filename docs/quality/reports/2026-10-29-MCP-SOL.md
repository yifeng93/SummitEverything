## 实现行为

14 个工具经官方 MCP Python SDK stdio 被发现和调用，bridge 只连接经过认证的 loopback FastAPI。支持目录、已确认知识搜索与版本读取、原件入收件箱及读取、草稿提交/编辑/读取、日历读取。固定 workspace 身份与严格输入 schema；模型不能通过工具签发批准。草稿提交意图、job、item 与 draft 关联可恢复，幂等键绑定完整内容，重放保留人工编辑/确认。正式内容仍使用原有用户确认流程。

知识搜索使用已有 LanceDB BM25，返回前复验共享内容资格与版本。无索引/旧索引分别返回明确状态，只有可用索引中无命中才为空列表；不会为搜索创建向量或调用模型。
