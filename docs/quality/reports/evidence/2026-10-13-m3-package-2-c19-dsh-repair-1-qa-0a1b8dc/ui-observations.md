# C19 repair-1 QA 实际浏览器观察

浏览器 surface：Google Chrome，通过 CUA 操作；地址为 http://127.0.0.1:15180/。测试库是本地隔离合成库 .local/qa/c19-repair-1/ui-api-workspace，含 9 页；Fake/offline 索引与答案路径，无外部连接。

操作与可见结果：
1. 首次打开该库时页面提示“本地索引尚未就绪”并要求完成当前模型版本索引。选择“准备索引计划”，再选择“按计划创建索引”，页面提示“已保存到本机：9 页，9 个新分块，复用 0 个。”这是测试前置索引过程。
2. 完整资料问答：实际问题为“白萤会展的年度访客信息登记办法是什么？”。回答显示“页面内容：白萤会展年度访客信息登记须核验身份并登记姓名。”，状态为“已确认资料中的陈述”；显示白萤会展页面引用，引用详情为“引用版本仍可用”。
3. 部分比较：查询“比较白萤会展的年度访客信息登记与汀屿计划的排期”。界面显示白萤会展的登记页面引用；同时明确显示“汀屿计划：缺少排期或启动时间依据。”以及“可用材料不足两组，无法进行跨材料比较。”
4. 零结果：查询“彩色牙刷的存储规则是什么？”界面没有引用，显示“彩色牙刷：缺少存储或保管规则依据。”
5. 信息性词缺失反控：查询“白萤近似的访客信息登记怎么办？”界面没有引用，显示“白萤近似：缺少访客信息登记依据。”与合成材料的少信息近似正文没有发生误引。
6. 同时有截断与真缺失：查询“比较云岬营地预算与汀屿计划的排期”。界面显示 5 条预算引用，仍明确显示“汀屿计划：缺少排期或启动时间依据。”，并显示“本次引用条数已达上限，另有同范围材料未列入引用；这不表示未覆盖主题已有依据。”
7. 纯截断：查询“云岬营地预算是多少？”显示 5 条预算引用及上限说明；未将上限说明误显示为缺少依据。
8. 历史重开：点击“新建对话”并执行完整查询后，在历史列表选择该条已完成记录。重开后原问题、答案和引用均可见，引用详情显示“引用版本仍可用”。停止服务期间 UI 曾显示 Failed to fetch；重启本地服务并重新打开已有合成库后，历史记录仍在，以上成功查询可重新打开。

复现边界：以上是可见 UI 操作与页面文字观察，不是 API 结果推断。DevTools console/network 导出和 PNG 截图保存接口在本次可用的 CUA surface 中不可用，记 NOT_RUN；UI 可见检查已完成。首次索引未就绪状态是预期前置状态，不计作缺陷。
