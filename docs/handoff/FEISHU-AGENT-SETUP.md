# 飞书 Agent 接入执行手册

本手册是复制提示词的补充材料。提示词正文自包含，助手当前目录、仓库源码和本文档均不是开始安全配置的前置条件。客户端/MCP 接通、飞书外部授权、SummitEverything 实际读取飞书数据是不同验证门。

## 定位运行实例

- 用户给出的网页 origin 用于寻找对应的本机运行实例；不能默认它等于 API origin，也不能从网页端口猜替 API 端口。若已验证的运行配置或服务接口证实 API 使用同源地址或受支持的本机代理，可使用该已验证通道。检查已连接的 SummitEverything MCP、宿主项目配置以及实际监听网页服务的进程/启动参数，交叉验证服务身份和工作库。只检查有限的相关证据，不全盘扫描。
- cwd、目录名和知识工作库路径都不能单独证明源码根目录。只有运行实例与源码目录匹配并得到验证后，才能将仓库文档路径相对该根目录解析；多个版本无法匹配时，按源码不可用继续提示词中的安全流程。
- 跨机器时不能把 localhost 当作用户原机器。若助手没有原机器的本机访问能力，不尝试连接或改配；报告缺少的最小访问信息/动作。

## 安全配置步骤

1. 检查宿主实际支持的 SummitEverything MCP、飞书工具/连接器、CLI/技能和现有授权，优先复用有效项；不覆盖无关 MCP 配置，不重复授权。当前 Summit MCP 有 14 个受限工具，不暴露设置/凭据，也没有 Feishu CLI bridge。
2. 对已验证的运行服务读取非秘密设置和凭据 configured 状态。API-v1 规定非秘密设置使用 `GET/PATCH /settings`、凭据使用 `PUT /credentials/{provider}`；先从运行服务或宿主证据核实 API origin、认证方式和支持的接口。不能默认网页 origin 等于 API origin，也不能猜替端口或凭据路径；若证实同源 API 或受支持的本机代理，则用已验证的通道。变更前读现值，只提交必要字段并保留其它设置。
3. 凭据只能从现有钥匙串/宿主秘密管理经受支持的本机安全通道提交到正式凭据接口。不得把密钥输出到聊天、终端、日志、提示词、仓库或普通配置；不得生成/覆盖 token 文件。缺少安全凭据来源或支持接口时，说明具体缺口和最小下一步。
4. 对每个读取 endpoint 核实其身份、scope 和目标资源归属，再与当前凭据身份/实际授予的 scope 对照。仅当 endpoint 支持且目标资源可访问时优先应用身份；只有 endpoint/功能明确要求 user token 时才请求相应用户授权。机器人/应用主日历不等于用户个人日历；凭据保存或 configured 仅证明存储状态。遇到 `missing_scope` 时确定具体缺失 scope 及适用身份：只为确需的 user scope 请求用户授权；app scope 则请管理员开通/审批相应应用权限。不得自动扩大 scope、切换身份或泛化要求 OAuth。日历只读在连接完成后可直接由应用/MCP 刷新：服务端仍核对当前工作库、身份、实际 scope、明确时间范围与有界请求；不要求一次性计划，失败不自动重试。材料/任务读取与材料导入须核对配置、工作库、endpoint、目标资源、范围及已确认的一次性计划；新计划通过应用流程展示待确认预览，不代替用户确认。其它外部结果为 unknown 时先查回执/状态，不自动重试。
5. 分别验证助手/MCP 到预期服务及工作库身份、外部飞书授权，以及 SummitEverything 集成是否成功读取了所需的目标资源。读取成功的证据应能核对 endpoint、身份、scope、请求范围和返回数据的用户/日历归属。返回 0 条或成功读取机器人主日历只证明对应日历可读，不能证明用户个人日历正确；资源归属、身份或 scope 无法确认时记为未验证，并给出最小下一步。不得创建任务、导入材料或确认正式知识。

不把 CLI 可运行、配置文件存在或工具列表出现说成应用已连通。报告应列出复用/修改的非秘密配置、各验证门的证据、未验证项及最小用户动作；不得包含密钥、token、授权码或带敏感参数的 URL。缺少仓库/文档不改变上述流程，也不要求普通用户先找源码。
