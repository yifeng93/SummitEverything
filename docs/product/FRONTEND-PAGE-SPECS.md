# SummitEverything 前端逐页规格

日期：2026-10-14。状态：**用户已确认**。配套文件：[FRONTEND-GUIDE.md](FRONTEND-GUIDE.md)（原则、tokens、守卫）、[ADR 0011](../decisions/0011-frontend-ux-baseline.md)（决策记录）。

**怎么用这份文件**：每个页面给出「区块顺序 + 每块写什么 + 三态 + 折叠项 + 不做什么 + 验收点」。
区块顺序是**规格**，不是建议：顺序变了要改这份文件并说明理由，不能顺手调。
所有页面都必须满足 GUIDE §4（文案）、§5（交互）、§6（样式）、§7（排版）、§9（细节分级）。

图例：**L1** = 主界面可见；**L2** = `<details>`「本次详情」/「技术信息」；**L3** = 只在诊断导出。

## 0. 应用外壳（`App.tsx` + 新 `components/AppShell.tsx`）

### 职责
让用户随时知道自己在哪、这个应用现在是什么状态、怎么换工作库。壳不承载业务。

### 结构（自上而下 / 自左向右）

1. **左侧栏（200px，`--sidebar` 背景）**
   - 品牌区：图标 + `SummitEverything` + 副标题「个人知识工作台」。副标题在 ≤640px 隐藏。
   - 主导航（恰好 5 项，顺序固定）：
     `今日` / `审批` / `项目` / `知识问答` / `设置`
     - 每项高 44px，图标 18px + 文案 14px，当前项 `background: var(--sidebar-active)` + 左侧 3px 强调条 + `aria-current="page"`。
     - **审批**项带数量徽章（待处理总数，`--danger` 底 + `--on-accent` 字）；为 0 时不显示徽章。
   - 底部：工作库名 + 首字头像 + 「切换…」；下方一行 `仅本机运行`（真实状态：本地服务可达 / 不可达，两种文案两种颜色）。
2. **顶栏（62px）**
   - 左：当前页面名（不是装饰性面包屑；只有进入项目详情/页面阅读时才显示"项目 / 页面名"层级）。
   - 右：保存状态（真实三态：`已保存` / `保存中…` / `保存失败，点击重试`），然后是主题切换（图标按钮，`aria-label` + `title`）。
   - 删除硬编码头像「罗」与永远为真的「本机已保存」。
3. **主内容区**：`max-width: 1200px` 居中，页头（eyebrow + `h1` + `.lede`）+ 各页区块。
4. **全局提示**：不再有一个常驻的红色横幅。错误走 toast（失败色）；需要停顿的错误用可关闭的就地提示块。

### 三态
- 加载：首屏显示"正在连接本机服务…"，**不显示**工作库向导。
- 错误：本机服务不可达时显示专门的就地页面/提示块：一句白话 + 「重试」+ 「查看日志目录」（L2 里给路径）；**不得**把它当成"还没有工作库"而弹出首次配置。
- 空（真的没有工作库）：才进首次配置向导。

### 不做什么
- 不做顶部页签改造（D5）。
- 不给「日志与思考」「飞书日常」留导航项；不加第 6 项。
- 不用 `⌄` 暗示不存在的下拉菜单。

### 验收点
- 导航恰好 5 项、标签精确、顺序固定；当前项有 `aria-current="page"`。
- ≤800px 折成 64px 图标栏，每个图标有 `title` + `aria-label`；≤560px 变底部 5 栏（每项 ≥44px）。
- 本机服务 500 时显示错误页而不是向导（对应守卫 ④ 的变体）。

## 1. 首次配置向导（App 统一宿主；复用 `WorkspaceGate.tsx` 与 `FirstUseWizard.tsx` 步骤组件）

### 职责
在一个流程里打开工作库、配置模型与密钥、检查连接并授权飞书。无工作库时先显示第 1 步；设置连接/重新授权入口打开同一向导并直达指定步骤。流程完成后不自动打扰，用户仍可从设置手动进入对应步骤。

### 结构（5 步，一条流程，可跳过、可中断续接）

**页头**：`SummitEverything` 标记 + 步骤指示（1–5，`aria-current="step"`）+ 「稍后再说」（跳过当前步）+ 「关闭」（退出向导，未完成也不阻塞浏览；第 1 步关闭回欢迎连接页，打开工作库后关闭回来源业务页）。
**主区**：当前步的内容，一次只显示一步。
**页脚**：`上一步` + 主操作（每步一个 `.button.primary`）。

| 步 | 标题 | 内容 | 主操作 |
|---|---|---|---|
| 1 | 选择工作库 | 两个选项：「新建」「打开已有」。**用原生目录选择器**（macOS 里就是「选择文件夹…」）；浏览器预览环境允许粘贴完整路径并给出示例。成功打开后在同一流程原地进入第 2 步，不先展示设置页再弹另一向导。 | 「创建/打开本地工作库」 |
| 2 | 模型与密钥 | 能力采用本机 Fake 默认；用户显式选择 Real 后才录入缺少的密钥。已配置凭据不重复要求输入。`type="password"` 字段只在内存中，成功保存/退出后清空；非必需步骤可跳过。缺少当前选择所需的必填项时禁用主按钮并用 `title` 说明。 | 「保存并继续」 |
| 3 | 检查连接 | 能力清单（整理与问答 / 知识索引向量化 / 检索结果排序），每项一行：名称 + 状态徽章（未检查 / 可以用了 / 失败，附下一步）。**不自作主张联网**：每项一个「检查这一项」按钮，点击后弹 `SmokeCheckConfirm` 范围预览，确认后才发。 | 「继续」 |
| 4 | 连接飞书 | 一句白话说明 + 「授权飞书」入口（经既有授权模块打开官方授权页）；状态只按本机授权状态接口展示。设置的连接/重新授权主操作复用此步骤。**非秘密接入值（App ID / callback / Base URL）不在这一步出现**（在设置高级区）。 | 「继续」 |
| 5 | 完成 | 汇总：工作库名、模型状态、飞书状态；以及一句话边界（"没做完的可以随时在设置里继续。"）。列出被跳过的步骤，各带一个"现在去补"入口。 | 「开始使用」→ 进入今日 |

### 三态
- 加载：读取本机设置时显示"正在读取本机设置…"（沿用现有诚实加载态）。
- 错误：字段级错误贴字段；连接失败显示原因白话 + 下一步（沿用 `settingsBadges.ts` 的映射，例如"账号还没有这个应用的使用权限 → 找管理员加进可用范围"）。
- 空：不适用（向导本身是空态入口）。

### 折叠项（L2）
- 第 1 步：工作库完整路径、库标识。
- 第 3 步：「本次详情」= 端点、模型名、请求次数上限、累计剩余次数。
- 第 4 步：正常流程不展示技术回调、App ID；设置高级区可查看必要的接入信息。
- L3：只进「设置 → 高级与自定义 → 诊断导出」。

### 不做什么
- 不把向导做成两条割裂流程（App 统一宿主持有步骤；工作库入口复用 gate 的表单逻辑，打开后原地进入后续步骤）。
- 不要求用户手敲 `/Users/you/...` 这类路径（原生选择器优先）。
- 不用"通知"代替必填校验。
- 不在保存后自动联网验证。
- 密钥不写入 localStorage / sessionStorage / 工作库；`type="password"` + `autoComplete="new-password"`，提交成功后立即从 state 清空。

### 验收点
- 在第 3 步且向导仍打开时页面重载，自动恢复第 3 步；恢复键由服务端返回的真实 profile + workspace 身份组成，不猜身份。
- 用户显式关闭后重载不自动弹；从设置手动继续可回到第 3 步。完成后重载不自动打开。
- 必填缺失时主按钮禁用，且 `title` 说明缺什么；已有凭据不重复要求录入。
- 所有入口只打开同一向导宿主；"稍后再说"跳过的步骤在设置页有对应入口。
- 首屏（服务可达、无工作库）先显示"正在连接…"，随后才进向导；服务报错时显示错误页而不是向导。

## 2. 今日（`components/TodayView.tsx`）

### 职责
一眼看完今天：要开的会、要做的事、要主动推进的事；顺手记一句。

### 主操作
「记一句」表单里的**保存**按钮（唯一 `.button.primary`）。

### 区块顺序（固定，不可增删）

1. **页头**：`今日` + 日期（`Intl.DateTimeFormat('zh-CN', { dateStyle: 'full' })`）+ 一句 `.lede`（"今天要开的会、要做的事都在这里。随手想到的先记一句，之后再整理。"）+ 右侧一个「重新生成简报」（ghost，`title` 说明耗时）。
   - 读取状态（失败时"本次读取失败，保留上次成功数据 · 最近成功读取于 …"）放在页头下方一行 `.hint`。
2. **今日简报 · 会议**：每行 = 时间（`tabular-nums`）+ 标题 + 行尾动作（`✎` 编辑，写回飞书日历）。已结束的会加「已结束」标签并降为 `--muted`，**不要**用整行透明度。
3. **今日简报 · 待办任务**：每行 = 截止徽章（今天=实底红 / 1–2 天=琥珀 / 一周内=蓝 / 更远=灰字）+ 标题 + 行尾 `✓` 完成、`✎` 编辑。
   - `✓` 完成后该行立即消失并计入"最近完成"；失败时保留该行并 toast。
4. **今日简报 · 需要行动**（有才显示）：不在任务清单里、但今天该管的（按 SE 的领域 = 行动建议 / 项目进度提议）。每行 = 标题 + 来源（中文名）+ 行尾「查看」。
5. **工具 · 记一句**：单行输入 + 保存按钮；下方 `.hint` 一句（"回车保存。之后可以在审批页决定它变成什么。"）+ 两个 ghost 入口 `工作日志` / `工作思考`（打开弹层）。
6. **工具 · 导入会议**：一句说明 + 「打开导入」（抽屉）。抽屉里 = 拖放区 + 逐文件状态列表 + 每个失败项「只重试此文件」+ 结果回执。
7. **收件箱（N 条）**：`记一句` 攒下的条目；每行 = 正文 + 元信息（`#项目` / 截止 / 承诺或想法）+ 行尾「提升为…」（打开目标选择弹层，默认已选一个，AI 建议是显式按钮且标「仅供参考」）。
   - 空态只有一句话，不占大块版面。

> 区块 5/6/7 在宽屏可并排（`grid-template-columns: minmax(0,2fr) minmax(280px,1fr)`，≤760px 单列）；区块 2/3/4 永远整宽纵向排列。

### 今日页不含（必须移除）
- 飞书授权按钮、材料搜索、日历创建表单、任何"模拟授权"入口（`FeishuPanel.tsx` 整体离开今日）。
- 待整理队列（intake items）与审核稿（drafts）→ 全部去审批页。
- 项目推进卡 → 去项目页。
- 右侧 rail 的"工作方式"步骤条（"1 保存来源 / 2 生成审核稿 / 3 确认后归档"）→ 删掉；它解释的是别人已经在做的工作流。
- 首页不要出现"待确认 N 条"这类属于审批页的计数（同一信息只在一处，且那一处要有"去处理"）。

### 三态
- 加载：三个内容区各显示骨架或"正在读取今日…"；**不得**显示"今天没有会议/没有任务"。
- 空：分别给三种：会议空（"今天没有会议。"）、任务空（"今天没有到期的任务。"）、需要行动空（整块不显示）。空态下不得出现 panic 色。
- 错误：区块级降级——某一块读失败只让那一块显示"这块暂时读不出来 · 重试"，其余照常。

### 折叠项（L2）
- 每一行任务/会议的 `title` 里放内部标识；
- 简报底部「本次详情」= 简报版本号、生成时间、数据来源。
- L3：不进今日页。

### 验收点
- 今日页只有 2 个工具 + 3 个内容区（守卫 ⑧）。
- 不含"授权飞书""待整理""审核稿""项目推进"任何字样（守卫 ⑧）。
- 唯一主操作是「记一句」的保存按钮。
- 加载中不出现空态文案（守卫 ④）。

## 3. 审批（新 `components/ApprovalView.tsx`，吸收 `DraftReview.tsx` / 待整理队列 / 正式内容确认 / 索引确认）

### 职责
所有需要用户点一下才算数的东西，按"先整理、再复核、最后确认"的顺序排在一页里。

### 主操作
工具栏的「检查并应用」只汇总用户选中的项目并按类别跳转审阅；不代替任何类别自己的范围预览、确认或执行，也不构成跨类别事务。

### 结构（固定顺序，每类一个分组，均带数量与空态）

1. **页头**：`审批` + `.lede`（"需要你点一下才算数的都在这里——先整理来源，再复核稿件，最后确认正式内容。"）+ **「怎么读这一页」说明段**（见下）。
2. **顶部状态行**：`待处理 N 项 · 共 M 类` + 视图筛选（全部 / 待处理 / 已完成）+ 右侧主操作「检查并应用」。
3. **分组 1 · 待整理的来源**（intake items）
   - 每行 = 复选 + 标题 + 来源文件名（中文）+ 状态（待整理 / 整理中 / 待审核 / 已完成 / 整理失败）+ 失败项的「只重试此项」。
   - 底部一排：主线下拉 + 项目下拉 + 「整理所选 · N」（primary）。
   - 真实模式：点击后先弹范围预览（`SmokeCheckConfirm` 口径），确认后才发。
4. **分组 2 · 待复核的稿件**（drafts，原 `DraftReview`）
   - 左侧稿件列表（标题 + N 个来源 + M 项冲突），右侧选中稿件的复核区：
     - 正文**渲染 Markdown**（不是源码，不是 `<pre>`）。
     - 与当前页面的差异（并排或 unified diff，渲染后对比，不是原始行）。
     - 冲突：单选选择保留哪一版 + 一个"暂时未决"选项。
     - 「来源」：可点开只读原文（沿用 SE 的引用来源口径，这是唯一保留完整路径的地方）。
   - 主操作：「确认并保存当前版本」（冲突未解决时禁用 + `title` 说明还差什么）。该既有原子接口会在用户明确确认后写入正式版本；不创建“已批准但尚未写入”的本地中间账本。
5. **分组 3 · 待确认的正式内容**（当前版本批准 / 需重新确认）
   - 每行 = 类型（中文映射：项目主页 / 知识页 / 业务决定 / 会议纪要 / 工作思考 / 工作日志 / 工作材料 / 周复盘）+ 待确认徽章 + 页面显示名 + 一句摘要 + 「查看完整正文」（`<details>`，渲染 Markdown）+ 「确认并保存当前版本」。该既有原子接口在用户确认时保存本版内容，不另设批准后等待应用的状态。
   - 必须写清边界：「只对当前这一版生效；文件改动后需要重新确认。不会创建飞书任务。」
6. **分组 4 · 待确认的索引更新**
   - 展示真实 `status` / `manual_required` 状态和已有计划 / 作业。仅首次索引、Real、模型变更、重建或服务标记 `manual_required` 的范围，提供「查看本次范围」和「确认更新」；显式预览确认后才创建计划或执行。Fake 活跃索引在正式内容确认后仍按产品规则自动增量，不额外变成待确认队列。
   - 范围细节（页面数、版本指纹、请求次数）进 L2。
7. **分组 5 · 待确认的外部动作**（飞书任务创建 / 项目进度变化）
   - 每行 = 可读标签 + 状态（已准备 / 发送中 / 已创建 / 创建失败 / **结果未知**）+ 独立操作。沿用 action 的确认后执行两阶段；结果未知只能「重新核对」或明确记录结果，不能自动重发。
8. **底部**：应用结果回执（成功/失败逐条），每条带"落在哪"的中文说明与可点开的入口。

### 「怎么读这一页」（固定段落，照 SWB）
必须解释四件事：
- 来源按可信入口标为「记一句」「文件」「飞书材料」；旧记录类型未知时显示「来源类型未知」，不从文件名猜。
- 原件只供整理和追溯，不进入检索；稿件确认会把所选当前版本写入正式内容。
- 索引的首次建立、Real 更新、模型变更、重建及服务要求手动确认的范围，都单独预览并确认；正式内容确认不会批准索引或飞书动作。
- 点「来源」可回看原文，核对整理稿与原件是否一致。

### 三态
- 加载：每个分组独立显示"正在读取…"。
- 空：分组级空态（"没有待整理的来源。导入的材料会先出现在这里。" / "没有待复核的稿件。" / "没有待确认的正式内容。" / "索引是最新的。" / "没有待确认的外部动作。"）
- 错误：分组级降级 + 可重试；一个分组读失败不影响其他分组（守卫 ④）。

### 折叠项（L2）
- 每条的 `title` = 内部标识 + 远端记录 id。
- 分组 1：「本次详情」= 服务/模型名、请求次数上限、累计剩余。
- 分组 4：范围明细（页面 id 数、版本指纹、分块数）。
- L3：只进诊断导出。

### 不做什么
- 不做"待确认审批"卡片出现在今日页。
- 不引入不存在的“已批准但未写回”中间状态：稿件和正式页的明确确认调用既有原子接口保存当前版本；外部 Action 则保留真实存在的确认后执行两阶段。
- 不用小字 `text-button` 承载删除/拒绝后的不可逆动作。
- 不在页面上展示 JSON、内部 id、状态枚举原文。

### 验收点
- 五个分组存在且顺序固定；每类有空态；数量与筛选一致（守卫 ⑧）。

## 6. 页面阅读页（`components/PageReader.tsx`）

### 职责
读一页知识，并决定它算不算当前正式内容。

### 主操作
状态相关的唯一主操作：待确认 → 「确认当前版本」；已确认但有新版本 → 「确认新版本」；历史版本 → 无主操作，只有「返回」。

### 结构

1. **返回行**：「← 返回项目」/「← 返回知识」。
2. **页头**：页面显示名 + 状态徽章（`待确认` / `已确认知识` / `已被替代`）+ 类型（中文映射）+ 版本时间。
   - **不显示 `relative_path`**（进 L2）。
3. **有效性提示**（必要时）：例如"引用保存的是回答当时的页面版本；该页面已更新，当前显示的是新版本，不能替代原回答依据。"
4. **正文**：`<MarkdownText>` 渲染，正文列 `max-width: 72ch`，系统无衬线 15px/1.75。代码块与路径用等宽。
5. **来源引用**（如果有）：可点开的"引用来源"，这里是**唯一**保留完整路径的地方。
6. **操作区**：主操作（见上）+ 「移动页面」（ghost，打开小弹层）+ 「编辑档案」按需。
7. **确认弹层**：确认当前版本前弹一次，写清"只对这一版生效；文件改动后需要重新确认"。

### 三态
- 加载："正在读取页面…"。
- 空：页面不存在 → 错误态处理（见下）。
- 错误：路径不存在/版本冲突 → 白话说明 + 「重新读取当前版本」；版本冲突必须给出"当前显示的是新版本，不能替代原依据"的提示。

### 折叠项（L2）
- 「技术信息」：完整路径、`content_sha256`、页面类型、版本时间。
- L3：诊断导出。

### 不做什么
- 不用 `<pre>` 显示正文（现在 `PageReader.tsx:112` 就是）。
- 不用等宽字体显示正文。
- 不在页头显示文件路径。

### 验收点
- 正文渲染 Markdown，可见文本无 `**` / `[[` / `##`（守卫 ⑥）。
- 状态徽章与主操作一一对应；历史版本没有"确认"按钮。
- 路径只在 L2 与"引用来源"出现。

## 7. 知识问答（`components/AskView.tsx`）

### 职责
问一句，拿到带出处的答案。

### 主操作
提问表单的「提问」按钮（唯一 `.button.primary`）。

### 结构（**提问框必须在第一屏第一块**）

1. **页头**：`知识问答` + `.lede`（"问一句，答案会带上出处。点出处能打开原文。"）。
2. **提问区**（第一块）：多行输入 + 「提问」（primary）+ 一行说明（"只使用已确认且仍是当前版本的页面；回答不会自动写入知识。"）。
   - 右侧或下方一个 ghost 入口：「新建对话」+ 历史入口（见 3）。
3. **本次范围**（真实模式）：一句白话 + 「本次详情」（L2）。
4. **答案区**：`<StreamingMarkdown>` 渲染，边流边排版（GUIDE §7.3）；流式期间显示"正在回答…"的 `role="status"`（固定文案，不在增长容器上）；有「停止」按钮（停止后保留已收到的部分并说明不会自动重发）。
5. **出处区**：每条 = 序号 + 页面显示名 + 区块标题 + 一句摘要；点开在应用内打开页面阅读页（带上当时的 `content_sha256`）。失效引用要明确标注"这条引用对应的页面版本已更新，不能作为当前依据"。
6. **历史对话**：默认折叠（一行标题 + 数量 + 「查看全部」）；常驻列表不属于第一屏。
7. **角色与记忆**：默认折叠在「问答偏好」里；展开后是原来的 CRUD 内容，但删除类动作要有确认。

### 三态
- 加载（索引状态）："正在读取本机索引…"；**不得**用"还没有本机索引"冒充加载中。
- 空：历史空（"还没有问答记录。问第一个问题吧。"）、索引空（"这台 Mac 还没有建立索引。建立后才能提问。" + 「建立索引」）。
- 错误：提问失败 → 就地错误 + 重试；模型未配置 → 专门文案 + 「去设置」；取消/信息**不得**走红色横幅。

### 折叠项（L2）
- 「本次详情」：服务与模型名、请求次数与上限、思考预算、耗时。
- 「问答偏好」：角色与记忆、检索参数。
- L3：`embedding_fingerprint`、页面 id 与版本、request_id、memory 的 `source_message_id`。

### 不做什么
- 不把历史、索引状态、角色与记忆排在提问框前面（现在 `AskView.tsx:477-524` 就是这样）。
- 不把 64 位 `fingerprint` 写进状态句（现在 `AskView.tsx:492` 就是）。
- 不在流式答案容器上挂 `aria-live`（现在 `AskView.tsx:576` 就是）。
- 不把答案用等宽字体整段显示。

### 验收点
- 提问框是第一块（守卫 ⑧ 的变体）。
- 答案渲染 Markdown 且流式中间态无未闭合标记（守卫 ⑥）。
- 列表/刷新不调用模型（守卫 ⑨）。
- 索引指纹不出现在可见文本（守卫 ①）。

## 8. 设置（`components/SettingsView.tsx`）

### 职责
连接工作库、模型、飞书；填一次就够。

### 主操作
每张卡自己的连接动作（同一屏可以有多张卡的主操作，但**每张卡内只有一个** `.button.primary`）。

### 结构

1. **页头**：`设置` + `.lede`（"连接工作库、模型和飞书。填一次就够，之后不用再管。"）+ 主题切换（跟随系统 / 浅色 / 深色）+ 一行模式说明（`试用模式（不联网）` / `正式连接（会联网）`，附「切换」）。
2. **主区三张卡，每张独占一行**（`grid-template-columns: minmax(0,1fr)`）：
   - **工作库**：显示名 + 服务端状态徽章 + 真实说明（正文保存在所选工作库；索引、聊天历史、凭据与诊断记录按本机 profile 管理）+ 「切换工作库」。
   - **AI 模型**：逐项列出整理与问答 / 知识索引向量化 / 检索结果排序的中文能力名、真实状态与下一步；模型名、账户与密钥收在高级配置。卡片唯一主操作「配置 AI 模型与密钥」。
   - **飞书**：逐项业务能力状态 + 一句下一步 + 唯一主操作「连接 / 重新授权飞书」（直达共享向导第 4 步）；技术 App ID、端点、callback、账号标识收进高级区。
3. AI 配置入口进入高级与自定义；设置页「连接 / 重新授权飞书」直达共享向导第 4 步。工作库卡的切换入口回到共享流程第 1 步。
4. **「高级与自定义」**（默认折叠，展开不改变数据）：端点与区域、账户标识、回调地址、能力状态明细、检查额度、预算、模型参数（只读）、诊断与日志、「设备与工作库标识」。分区标题按内容分组，别堆成一个长列表。
5. **危险区**（放在「高级与自定义」底部）：按密钥项删除本机密钥。**每项都有确认弹层**，写清只删除所选密钥且工作库文件不会删除；该钥匙串密钥删除后无法从本机恢复。断开飞书/移除工作库仅在有对应真实动作后展示。

### 三态
- 加载：显示明确的本机设置读取状态，不能伪装成空态或已连接。
- 错误：设置读取失败时三张卡各自显示"暂时无法读取"与重新读取入口；成功状态不得由单一模型检查或失败的读取推断。
- 空：未配置就是未配置，徽章说清下一步（不显示空白）。

### 折叠项（L2）
- 端点、区域、维度、账户标识、callback、预算、模型参数、读取时间。
- L3：`embedding_fingerprint`、完整工作库路径、设备标识，只在诊断导出里。

### 不做什么
- 不把自动化/设备/诊断放在主区（现在已收进折叠区，保持）。
- 不在主区让用户手填 Base URL / callback / App ID。
- 不显示"请勿在聊天中发送密钥"这类面向开发团队的文案（该说的在向导字段旁用一句白话说明即可）。
- 不在深色下用写死的浅色背景（守卫 ⑦）。

### 验收点
- 主区恰好 3 张纵向卡（工作库 / AI 模型 / 飞书），每张只有一个主要操作（守卫 ⑧）。高级区默认折叠；刷新、展开、保存不调用 provider。危险操作确认前不写入，确认后仅删除所选密钥。
- 深色下输入框、通知条、徽章全部可读（守卫 ⑦）。
- 每张卡独立降级，单卡失败不影响其他卡。
- 危险动作都有确认弹层（守卫 ⑤）。

## 9. 共享组件规格

| 组件 | 规格 |
|---|---|
| `<MarkdownText>` | GUIDE §7.2。唯一允许渲染用户内容的入口；默认不渲染原始 HTML；链接外开 + `rel="noreferrer noopener"`；内部页面链接走 `onOpenPage` |
| `<StreamingMarkdown>` | GUIDE §7.3。`stabilize()` 容错 + 尾部光标 + 结束时以完整 buffer 收敛；不挂 `aria-live` |
| `<Toast>` / `useToast()` | GUIDE §5.2。右下角固定列，最多 3 条，成功 3.5s，失败常驻可手关；文案不含 ID/路径 |
| `<ConfirmDialog>` | `role="dialog"` + `aria-modal="true"` + 焦点陷阱 + Esc + 焦点归还；标题写动作、正文写影响与可恢复性、主按钮 `.button.danger` |
| `<EmptyState>` | 图标/标记 + 一句话原因 + 一个可点入口；中性语气 |
| `<LoadingBlock>` | 骨架或"正在读取…"；**不得**与 `<EmptyState>` 混用 |
| `<StatusBadge>` | 只用 `--ok/--warn/--danger/--quiet` 四类语义；文案经纯函数映射，未知值给"需要处理"而不是空白 |
| `<PageHeader>` | eyebrow（可选）+ `h1` + `.lede` + 右侧动作区（≤1 个 primary） |
| `<Details>`（L2 折叠） | 统一标题「本次详情」或「技术信息」；`<summary>` 可键盘操作，展开不改变数据 |
| 危险动作按钮 | `.button.danger`，只出现在确认弹层与列表行内次要位置；≥36px（细指针）/44px（粗指针） |
