# ADR-004：模拟开发先行与独立验收

状态：Accepted。日期：2026-10-09。依据：用户最后三道选择题与补充授权。

## 背景

原讨论计划把场地与酒店业务确认放在开发前。用户现在要把完整框架交给执行 Luna，并在合适时候处理真实样板；另一个 Luna 独立测试。

## 决定

通用开发立即用隔离模拟材料开始，样板业务确认是实际初始化前的数据门。允许本轮补最小参考框架代码，应用与业务功能由执行者实现。

文档覆盖完整第一版。执行者负责实现与修复，验收者可增补测试和报告缺陷，但不改产品实现。每阶段固定代码提交交接，验收使用独立工作目录。

## 影响

旧的“样板未确认则任何编码不能开始”顺序被本决议替代。模拟通过只证明流程与契约，不能替代真实内容、模型质量、权限、单机试用或双机证据。这个边界同时写入进展账本与两份提示词。
