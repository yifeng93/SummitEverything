# ADR 0025：移除外壳顶栏

日期：2026-10-29。状态：Accepted。用户指出顶栏只有一个「项目」字样，重复了页面自己的 h1，没有意义，要求去掉。此 ADR 只改外壳，不改任何页面内容与数据。

## 背景

外壳顶栏 62px，左侧显示当前导航项名称，进入页面阅读时再拼成「项目 / 页面名」；右侧放保存三态。侧栏已经用当前项高亮表示「我在哪」，页面自己又有 h1，顶栏的左侧基本是重复信息。空态下这条 62px 的横条只剩两个字，还占掉了首屏高度——前一轮已经因为顶部占高调整过项目详情，这一条就变成纯成本。

## 决定

1. **移除顶栏**（`.topbar` / `.crumbs` / `.topbar-right` 一并删除）；`AppShell` 不再接收 `openPageTitle`，`App` 不再计算它。
2. **保存三态搬到侧栏底部**，在紧凑工作库选择器上方；空闲时不渲染、不占位。侧栏恒为深色底，配色改用 `--sidebar-*` token。
3. ≤800px 图标栏与 ≤560px 底栏不显示保存状态（与原来的移动端行为一致）。
4. 页面阅读页的「项目 / 分类」面包屑仍在阅读页内部，不依赖外壳。

## 后果

- `ui-contract.test.ts` 外壳几何守卫从「顶栏必须 62px」改为「不得存在 `.topbar` 高度规则」；其余几何（侧栏 200px、内容 1200px、44px 导航项、3px 强调条）不变。
- `AppShell.test.tsx` 删除面包屑用例，改为断言外壳不渲染顶栏；保存三态用例不变（按文本查询，位置无关）。
- 每个页面首屏多出 62px 可用高度。
- 顶栏原本是唯一的全站「当前页名」文本；移除后页面名称只在各页 h1 与阅读页面包屑里出现，属于预期收敛。
