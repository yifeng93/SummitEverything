# ADR-001：统一产品与 DMG / WebUI 交付

状态：Accepted。日期：2026-10-09。依据：用户已确认。

## 背景

用户同时维护 SWB、工作库和 SK，每次业务调整需要三端协调。工作目标是固定的材料输入、知识确认和复用流程。使用设备是两台 Mac，未来同事也应能单机使用。

## 决定

应用名称 SummitEverything，新仓库独立实现整理与检索。首版每台电脑各自运行，DMG 安装、双击使用；内部采用 WebUI 与本地后端，Swift 只作为壳。

## 比较

Docker WebUI 能封装服务依赖，但本机使用仍需容器环境、目录挂载和凭据配置。用户选择单应用安装体验。集中常开服务器会改变数据位置与设备共享边界，用户选择各机独立运行。

纯 SwiftUI 可做原生界面，但会减少旧 Web 能力复用并扩大 UI 维护范围；WebUI 不要求 Docker，可以在 DMG 内使用。

## 影响

维护一个界面和一个后端。首版不交付 Docker，不引入团队账号与服务器部署。系统集成与业务隔离，未来有真实需求时可增加另一种封装，但现在不同时维护两套验收面。
