# ADR-002：当前版本批准与可迁移 Markdown

状态：Accepted。日期：2026-10-09。产品语义用户确认，hash 细节为工程基准。

## 背景

用户把知识库作为核心资产，希望外部工具可读、可以外部编辑，同时避免原件和未确认推断污染检索。项目结束、内容确认和规则失效含义不同。

## 决定

普通目录保存 Markdown；稳定 ID 跟随内容身份。正式版本带批准证明，任何语义改动失效。原件、稿件和辅助状态始终排除；索引与查询复用同一资格规则，查询最终使用前复验当前文件。

内容确认、业务进展、知识效力分开。归档知识仍可查询；失效 / 被替代知识默认仅历史查询可使用。原件另行保留，既不检索也不能通过改标签进入语料。

必要待处理业务状态可迁移，SQLite、会话、角色、记忆、日志和秘密留在各机本地。OneDrive 负责文件同步，用户确认后交接写端。

## 比较

只用 approved 标签不能发现外部编辑后的旧批准；仅在索引阶段过滤仍会使用旧缓存。把运行中的 SQLite 同步到 OneDrive 会让文件同步承担数据库一致性。只同步最终页则丢失待审流程。

## 影响

增加版本检查、恢复及状态压缩的实现成本，得到可解释的语料资格与设备切换边界。证明是个人工作流程记录，不是数字签名或多用户身份认证；原件路径防线和本地 API 认证仍必须实现。
