# ADR 0014：工作库入口只保留必要的四件事

日期：2026-10-28。状态：Accepted。只改首次进入时的第 1 步（`WorkspaceGate`），不改工作库创建/打开 API、首次配置后续步骤或任何确认门。

## 背景

原页面同时放了：步骤口号「首次配置 · 第 1 步，共 5 步」、「先打开工作库…」提示块、31px 衬线大标题、两行说明、路径示例说明、底部隐私脚注。用户的实际任务只有两个：新建一个工作库，或打开已有工作库；需要填的只有名称和文件夹路径。其余文案不帮助完成这一步，反而让主操作不突出。

## 决定

1. 标题随模式变化：`新建工作库` / `打开工作库`；不再使用装饰性大标题与步骤口号。
2. 模式改为两段等宽切换（新建 / 打开已有），整段可点击；保留原生 radio 语义。
3. 主区只有字段：工作库名称（仅新建）与文件夹路径；原生壳在路径右侧提供「选择…」，浏览器预览直接输入路径。
4. 删除：「先打开工作库…」提示块、路径输入说明、底部「内容仅写入本机…」脚注、品牌副标题、页面说明段。
5. 错误仍就地显示在表单内；主按钮文案保持「创建本地工作库 / 打开工作库」。
6. 隐私与内容边界不在这里重复：导入材料、正式内容确认和真实调用预览处已有更准确的说明。

## 后果

- `WorkspaceGate.test.tsx` 的标签与按钮名称不变，行为测试无需放宽。
- 首屏从约 760px 高、六层信息压到一列 400px 的表单；新建模式只有模式、名称、路径、主按钮四层。
- 同日追加（用户标注）：去掉外层卡片边框与背景，品牌行、标题与表单列在页面背景上整体居中；不再有“悬浮卡片”的容器感。
- 后续步骤仍由同一向导承接；打开成功后原地进入第 2 步，落点不变。

## 同一原则用于向导第 2 步

用户在同一轮指出首配整体应更简洁。第 2 步同步收敛：能力行只保留名称与模型名；三个服务地址收进一行折叠「服务地址」，默认不展开；删除「工作库：已连接…」的重复说明与「用于整理与问答 / Embedding 与 Rerank 共用」的冗长前缀。密钥字段与校验保持不变。
