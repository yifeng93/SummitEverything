# ADR 0034：当前回答优先于问答历史

- 日期：2026-10-30
- 状态：已采纳

## 背景

问答历史列表可能占据多行。流式回答原先排在历史列表后面，用户需要滚动才能看到正在生成的内容；追问时当前回答也可能排在既有对话轮次之后。

## 决定

提问区之后先显示本次真实发送预览（如有）和当前回答，再显示最近问答列表或既有对话轮次。回答完成后，回答仍按现有对话记录渲染。保留当前的状态、停止、错误恢复与出处行为，不自动滚动，也不隐藏历史。

## 影响

当前输出在页面流中靠近提问区，历史和既有轮次仍可继续查看。问答页顺序见 [逐页规格](../product/FRONTEND-PAGE-SPECS.md#7-知识问答-componentsaskviewtsx)。
