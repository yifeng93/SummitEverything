# ADR 0029：飞书主连接入口交给本机助手配置

- 状态：已决定（2026-10-29）
- 背景：今日页的连接入口不能启动手动配置向导；用户希望本机助手检查并复用现有 MCP、飞书授权和本机配置，减少重复手工设置。
- 决定：今日与设置主区的「连接飞书」均复制同一份自包含 Codex / WorkBuddy 提示词。提示词带当前应用 origin（不含 query/hash），引导助手发现本机支持能力、读取 MCP/API 契约和接入手册，并安全复用授权。复制成功只提示粘贴到助手；拒绝剪贴板时显示可选择文本和重试。设置的高级 / 兼容区继续保留手动配置。
- 安全与验证边界：当前 Summit MCP 有 14 个受限工具，不暴露设置/凭据且无 Feishu CLI bridge；助手仍须检查 API-v1 的非秘密设置与正式凭据接口、宿主安全凭据来源。提示词不代替真实授权，不把客户端连通当作应用实际读取，也不授权写任务、确认知识、付费调用或绕过有效一次性计划。缺安全凭据来源时报告最小动作，不在聊天传密钥。
- 执行手册：[飞书 Agent 接入执行手册](../handoff/FEISHU-AGENT-SETUP.md)。
