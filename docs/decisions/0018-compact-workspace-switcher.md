# ADR 0018：工作库选择器收成底部紧凑菜单

日期：2026-10-28。状态：Accepted。只改底部工作库入口的形态，不改变切换工作库的确认、落点或工作库身份。

## 背景

原来的工作库入口是一条占满侧栏宽度的描边卡片：头像 + 库名 + 永远显示的「切换…」副行。它和导航、外观入口抢视觉重量，且「切换…」暗示一种持续可见的操作，实际切换工作库是低频动作。用户要求参考 Codex / WorkBuddy 的底部账户区：小、安静、点开再操作。

## 决定

1. 工作库入口改为一行紧凑选择器：24px 首字头像 + 当前库名（单行省略）+ `ChevronsUpDown` 上下箭头；高度 32px，默认无边框、无底色，仅 hover / 展开时给侧栏高亮。
2. 点开后在按钮上方弹出小菜单（`role="dialog"`，标题「工作库」），当前只放一个动作「切换工作库」；点击后关闭菜单并沿用原有 `onSwitchWorkspace` 流程。
3. 菜单与「外观」菜单共用同一套开合逻辑：同时只开一个，点外部关闭，Escape 关闭并把焦点还给触发按钮。
4. 删除「切换…」副行、描边卡片和 `.workspace-name` 旧样式；≤800px 时只显示头像，名称与箭头隐藏。
5. 切换工作库的未保存稿件确认、首次配置落点均不变。

## 后果

- 侧栏底部变成两个安静的入口：工作库选择器 + 外观；导航不再被一块大卡片压住。
- `AppShell` 与 `App.shell` 的切换测试改为「打开工作库菜单 → 点切换工作库」，行为断言不变。
- 后续如果要加「最近工作库」或「新建工作库」，直接在该菜单里加行，不再改触发按钮。
